# Dr. Akash Shah — Uro-Oncology & Robotic Surgery

A specialized, clinical-grade digital platform for **Dr. Akash Shah**, Fellowship-trained Uro-Oncologist & Robotic Console Surgeon based in Bandra West, Mumbai.

Built with a quiet-luxury editorial aesthetic, evidence-based surgical pathways, WCAG AA accessibility, interactive 3T mpMRI diagnostic showcases, multi-hospital chamber routing, and an instant WhatsApp clinical triage concierge.

---

- **Robotic Radical Prostatectomy**: Nerve-sparing console precision, 10× 3D optical magnification, and early continence recovery.
- **Partial Nephrectomy (Nephron Sparing)**: Zero-ischemia margin control and maximal renal functional preservation.
- **Transperineal MRI-Ultrasound Fusion Biopsy**: 3D co-registered sub-millimeter targeting with zero sepsis risk.

- **Active Surveillance Protocols**: NCCN-guided multiparametric serial staging.

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables Design Tokens
- **Typography**: Zodiak Serif (Display) + Plus Jakarta Sans (Body) via Fontshare
- **Motion & Smooth Scroll**: GSAP (ScrollTrigger) + Lenis
- **Iconography**: Phosphor Icons React (`@phosphor-icons/react`)
- **Accessibility**: 100% WCAG AA compliant color contrast (13/13 token pairs audited)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Skullcandy45/akash-shah.git

# Navigate to project directory
cd akash-shah

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build & Verification

```bash
# Verify WCAG AA design token contrast
npm run contrast

# Production build
npm run build
```
